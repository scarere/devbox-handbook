# Claude Code Usage

[ccusage](https://ccusage.com/) is a useful CLI for analayzing the usage and cost of your coding agent. Works with any agent type.

Install with

```zsh
bun install -g ccusage
```

## Usage

```zsh
ccusage            # usage and cost per day (same as `ccusage daily`)
ccusage monthly    # per month (also: weekly, session)
ccusage --help     # all commands
```
