# Eza

[Eza](https://github.com/eza-community/eza) is a modern alternative to ls. Install it with homebrew

```bash
brew install eza
```

Then alias `ls` and `ll` to `eza` in `~/.zshrc`. [zshrc](../../../shells/zsh/.zshrc) already has this in it and defaults to `ls` if `eza` is not installed.

Eza is nice because the spacing between columns is better/dynamic. Also the formatting/colors of different filetypes is nice and included by default.
