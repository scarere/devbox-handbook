# Astral Packages

The astral ecosystem of packages can be installed both as python packages, vscode extensions or as standalone system packages. The current suite of astral tools includes

- [uv](https://docs.astral.sh/uv/): Python package manager
- [ruff](https://docs.astral.sh/ruff/): Python linter and code formatter
- [ty](https://docs.astral.sh/ty/): Python type checker and language server
